# 참고 스티커 이미지

2026-10-12 사용자가 표시한 두 스티커를 기준으로 built-in ImageGen으로 투명 PNG를 제작했습니다. 달력과 팝업에서 같은 파일을 사용합니다. 기존 SVG는 보존합니다.

- `arrival-reference.png`: 출근 캐릭터, 흰 셔츠·분홍 넥타이·검은 가방, 파란 알람시계, 분홍 배경과 주황 강조선.
- `night-reference.png`: 하품하는 파란 노트북, 작은 양손, 빨강·흰색 알람시계, 노란 배경과 주황 강조선.

프롬프트 요지: 첨부 달력의 각각 빨간 원으로 표시한 일러스트만 투명 배경으로 분리·재현하고, 날짜·달력·빨간 주석·문구를 제거한다. 원본의 귀여운 손그림 스타일과 인물·노트북·시계 구성을 유지하며, 문구는 기존 HTML 라벨로 표시한다.

원본에서 픽셀 단위로 잘라낸 파일이 아니라 참고 이미지에 맞춰 재현한 일러스트입니다.
