# 의사소통 카드 삽화

- 파일: `communication-illustrations.png` (상단 3장면·하단 2장면과 빈 셀로 구성).
- 방식: built-in image_gen. 대화로 첨부된 인포그래픽의 삽화·구도를 참고해 글자 없는 그림으로 재구성했습니다. 원본 파일을 직접 잘라낸 결과는 아닙니다.
- 사용 프롬프트: 첨부의 파란 테두리 의사소통 인포그래픽만 참고해 회의하는 세 동료, 다섯 하위능력의 퍼즐, 오해하는 두 동료, 표현·피드백·경청 도형, 협업하는 네 동료의 삽화를 3열×2행 이미지로 정리. 얇은 윤곽선과 차분한 파랑·회색·초록의 교육용 만화 표현, 크림 배경, 장면별 여백을 유지하고 모든 본문·번호·인용·로고·워터마크를 제거.
- 웹 본문은 `communication-content.js`에서 수정합니다. 그림 속에 교정 본문을 삽입하지 않습니다.
