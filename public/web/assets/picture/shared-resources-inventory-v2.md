# 비품 목록 3번 카드 순차 체크

기존 시트의 오른쪽 위 장면을 imagegen으로 편집해 체크 표시만 제거한 독립 이미지입니다. 네 개의 빈 체크박스와 배경 물품은 유지했습니다.

별도 SVG 레이어에 첫 체크를 고정 표시하고, 나머지는 각각 0.65·1.3·1.95초 뒤부터 0.5초 동안 선이 그려지도록 구현했습니다. 한 번 재생한 뒤 모든 체크를 유지합니다. 모달로 비활성화된 동안은 일시 정지하며 동작 줄이기 설정에서는 모두 체크된 상태로 표시합니다.

브라우저에서 초기 1개, 이후 2개·3개·4개 순서의 실제 SVG 상태와 최종 이미지 정렬을 확인했습니다.
