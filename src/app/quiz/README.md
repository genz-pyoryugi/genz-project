# 회사 생활, 나라면? 퀴즈

브랜치: `feature/quiz`. 실행: `npm run dev`, `/quiz` 접속.

## 데이터와 재사용 범위

`frontend`의 `public/web/js/components/quiz.js`, `src/app/api/[table]/route.ts`, `public/web/js/data/chapters.js`를 확인했습니다. 전체 브랜치를 병합하지 않았습니다. 첫 화면을 유지하기 위해 `frontend`의 `src/app/page.tsx`, `public/intro/`만 원본 그대로 가져왔습니다. 기존 `src/lib/supabase.ts` 및 `.env.local`은 수정하지 않았습니다.

- 테이블: `quizzes`
- 필드: `id,category,question,option1,option2,option3,option4,option5,answer,explanation`
- 공개 필터: `status = 완료`, 정렬: `id` 오름차순
- 7개 주제의 이름·순서는 기존 chapters.js와 동일
- 기존 프런트엔드처럼 서버에서 공개 행을 읽고 category에서 공백을 제거해 주제별로 분류
- 선택지 순서: `option1`부터 `option5`; 빈 문자열·null은 제외
- 정답 형식: `선택지1` 또는 `선택지 1` 등의 문자열. 원래 필드 번호를 유지해 빈 선택지가 있어도 올바르게 매핑
- 유효 문제 기준은 기존 구현과 동일: 질문 있음, 유효 선택지 2개 이상, 정답이 존재하는 선택지에 연결됨
- 실제 데이터 문구와 해설을 그대로 렌더링. 잘못된 데이터나 빈 결과는 예시 문제로 대체하지 않음

## 동작

초기에는 미선택. 선택 후 확인 버튼을 눌러야 채점하며 채점 후 선택은 잠깁니다. 확인 버튼 중복 동작이 점수를 중복 증가시키지 않도록 보호합니다. 정답·오답 상태와 저장된 해설을 표시하고, 다음 문제·최종 점수·다시 풀기를 제공합니다. 주제 전환 시 해당 주제를 처음부터 다시 시작합니다. 결과는 React 화면 상태에만 있으며 데이터베이스·localStorage에는 쓰지 않습니다. 닫기 링크는 `/`를 통해 기존 `/intro/index.html`로 이동합니다.

긴 문장과 해설은 종이 안에서 스크롤하고 PC의 확인·다음 버튼은 항상 보입니다. 모바일은 자연스러운 페이지 스크롤로 모든 문장을 읽을 수 있습니다. 라디오 선택의 키보드 접근성과 주제 탭의 방향키/Home/End, 포커스·감소된 모션을 지원합니다.

## 자산·폰트

- `public/quiz/assets/office-background.png`: 따뜻한 사무실 배경만
- `public/quiz/assets/pen-mascot.png`: 투명 배경 펜 캐릭터만
- `public/quiz/assets/office-conversation.png`: 장식용 사무실 동료 삽화
- `public/quiz/fonts/`: 기존 체크리스트에서 사용한 Jua·Noto Sans KR와 OFL 라이선스

첨부 이미지 전체를 배경으로 사용하지 않았습니다. 배경·캐릭터·삽화는 built-in ImageGen으로 참고 이미지의 해당 부분을 최대한 보존해 재현한 별도 자산입니다. 원본을 픽셀 단위로 잘라낸 자산은 아닙니다. 제목·탭·문제·선택지·버튼·응원 말풍선은 실제 HTML 요소입니다. 이미지의 정확한 폰트명은 확인할 수 없어 Jua 제목과 Noto Sans KR의 두께·크기·자간으로 가깝게 맞췄습니다.

최종 프롬프트 요지: (1) 첨부 퀴즈의 종이·글씨·UI·캐릭터를 제거하고 따뜻한 책상·남색 파티션·식물·사무실만 재구성, (2) 남색 광택 몸체·금색 클립과 펜촉·흰 장갑·웃는 얼굴의 펜만 투명 배경으로 보존, 말풍선과 글씨 제거, (3) 질문하는 크림색 옷의 여성과 파란 셔츠의 남성 삽화만 재현.

## 확인 (2026-10-12)

- 실제 Supabase/API HTTP 200, 7개 주제 각각 3문제, 총 21문제. 현재 데이터 선택지 5개·해설 모두 있음.
- 모든 문제의 질문·선택지 순서·정답·해설을 실제 API 데이터와 대조.
- 미선택 초기 상태, 확인 전 답 변경, 정답·오답 채점, 다음 문제, 점수, 다시 풀기, 빈 선택지의 원래 번호 매핑 검증.
- 1672px PC와 390px 모바일 스크린샷 시각 확인. 긴 실제 문제, 응답 상태·오류·재시도, 키보드 탭, 닫기 링크 검증.
- 빈 목록·연결 오류·로딩 상태는 격리된 브라우저 검증에서만 응답을 제어. Supabase 데이터는 수정하지 않음.
- ESLint·페이지의 별도 TypeScript 검사 통과. 브라우저 런타임 오류 및 데이터 변경 HTTP 요청 없음.
- 전체 프로덕션 빌드는 별도 검증하지 않음. 커밋·GitHub 푸시하지 않음.

기존 로컬 `public/learning/`, `team-handoff/`, 기타 미추적 작업 파일은 보존했습니다. `.tools/`는 검증용으로 Git 제외합니다. 향후 커밋할 때는 이번 화면·API·자산·첫 화면 유지 파일만 선택해 포함하세요.
