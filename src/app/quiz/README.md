**현재 학습 기록 설정:** [내 학습 기록·운영자 화면 안내](../../../docs/learning-history-setup.md). 기록 기능에는 기존 두 마이그레이션 다음으로 `202610200001_learning_history.sql` 적용이 필요합니다.

**완료 화면:** [캐릭터 자산·AI 팀장 시뮬레이션 연결](../../../docs/quiz-completion.md). 완료 화면의 이동 버튼은 AI 팀장 시뮬레이션으로 연결되며, 학습 기록은 `/learning`에서 확인합니다.

**파트별 이어 풀기:** [진행 상태 저장·동기화 안내](../../../docs/quiz-progress.md). 학습 기록 SQL 다음에 `202610200002_quiz_progress.sql`을 적용합니다.

브랜치: `feature/quiz`. 실행: `npm run dev`, `/quiz` 접속.

## 데이터와 재사용 범위

`frontend`의 `public/web/js/components/quiz.js`, `src/app/api/[table]/route.ts`, `public/web/js/data/chapters.js`를 확인했습니다. 전체 브랜치를 병합하지 않았습니다. 첫 화면을 유지하기 위해 `frontend`의 `src/app/page.tsx`, `public/intro/`만 원본 그대로 가져왔습니다. 기존 `src/lib/supabase.ts` 및 `.env.local`은 수정하지 않았습니다.

- 현재 카탈로그: `lt_catalog()` RPC. 공개·목록 표시된 최신 퀴즈 버전과 고정된 문제 버전을 사용합니다.
- 기존 `quizzes` 데이터는 `supabase/import_quizzes_table.sql`로 버전 테이블에 가져옵니다. 화면에서 원본 `quizzes`를 직접 읽거나 수정하지 않습니다.
- 선택지 순서와 정답 ID는 카탈로그의 `options`, `correctOption`/`correctOptions`를 사용합니다. 복수 선택은 선택한 ID의 집합이 정답 집합과 같아야 정답입니다.
- 7개 주제는 조직 이해&적응, 업무 절차&기준, 질문&소통, 협업&동료 존중, 직장 내 관계&예절, 근무&재택 수칙, 공용 공간 & 비품 관리입니다.
- 실제 데이터 문구와 해설을 그대로 렌더링. 잘못된 데이터나 빈 결과는 예시 문제로 대체하지 않음

## 동작

초기에는 미선택. 선택 후 확인 버튼을 눌러야 채점하며 채점 후 선택은 잠깁니다. 확인 버튼 중복 동작이 점수를 중복 증가시키지 않도록 보호합니다. 정답·오답 상태와 저장된 해설, 다음 문제·최종 결과·오답 복습·AI 팀장 연결을 제공합니다. 사용자·파트별 진행 상태를 localStorage와 sessionStorage에 보관하고 Supabase에도 동기화합니다. 돌아오면 ‘이어 풀기 / 처음부터 풀기’를 선택하며, 처음부터 풀면 이전 응시는 중단 기록으로 보존합니다. 공유 추적기의 영속 outbox로 공식 답안과 진행 상태를 전송하고, 최종 저장 점수는 서버가 채점합니다. 저장 안내 문구는 화면에서 숨겼지만 자동 저장·재전송은 유지합니다. 학습 기록은 `/learning`에서 조회합니다. 기록·비교·권한·SQL 적용 기준은 위 안내를 따릅니다. 닫기 링크는 `/`를 통해 기존 `/intro/index.html`로 이동합니다.

긴 문장과 해설은 종이 안에서 스크롤하고 PC의 확인·다음 버튼은 항상 보입니다. 모바일은 자연스러운 페이지 스크롤로 모든 문장을 읽을 수 있습니다. 라디오 선택의 키보드 접근성과 주제 탭의 방향키/Home/End, 포커스·감소된 모션을 지원합니다.

## 자산·폰트

- `public/quiz/assets/office-background.png`: 따뜻한 사무실 배경만
- `public/quiz/assets/pen-mascot.png`: 투명 배경 펜 캐릭터만
- `public/quiz/assets/office-conversation.png`: 장식용 사무실 동료 삽화
- `public/quiz/fonts/`: 기존 체크리스트에서 사용한 Jua·Noto Sans KR와 OFL 라이선스

첨부 이미지 전체를 배경으로 사용하지 않았습니다. 배경·캐릭터·삽화는 built-in ImageGen으로 참고 이미지의 해당 부분을 최대한 보존해 재현한 별도 자산입니다. 원본을 픽셀 단위로 잘라낸 자산은 아닙니다. 제목·탭·문제·선택지·버튼·응원 말풍선은 실제 HTML 요소입니다. 이미지의 정확한 폰트명은 확인할 수 없어 Jua 제목과 Noto Sans KR의 두께·크기·자간으로 가깝게 맞췄습니다.

최종 프롬프트 요지: (1) 첨부 퀴즈의 종이·글씨·UI·캐릭터를 제거하고 따뜻한 책상·남색 파티션·식물·사무실만 재구성, (2) 남색 광택 몸체·금색 클립과 펜촉·흰 장갑·웃는 얼굴의 펜만 투명 배경으로 보존, 말풍선과 글씨 제거, (3) 질문하는 크림색 옷의 여성과 파란 셔츠의 남성 삽화만 재현.
