# 의사소통능력 실제 원고 적용

## 구현

- 원고: `public/web/js/data/newsletter-content.js`. 세로형 `communication-content.js`와 분리했습니다. 카테고리는 기존 `collaboration`, ID는 기존 응답 연결을 유지하는 `communication-newsletter-test`입니다.
- 각 장은 `title`(상단 라벨), `message`(메인 제목), `panel`(오른쪽 상단), `blocks`(설명 3개), `highlight`(하단 강조), `takeaway`(전체 하단 핵심 정리)로 구성합니다.
- 사용자가 전달한 5장 원고를 삭제 없이 웹 텍스트로 적용했습니다. 2장의 직접 요청 문장은 `panel.quote`로 분리했습니다. 배치 지시는 `imageInstruction`에만 저장하고 화면에 표시하지 않습니다.
- 1200×675, 베이지·파랑·Pretendard·탐색 버튼을 유지합니다. 긴 원고에 맞춰 제목 32px, 본문 14px, 항목 제목 15px, 핵심 정리 16px로 설정했습니다. 박스는 내용에 따른 자연 높이를 사용합니다.
- 자기진단은 같은 목표를 기준으로 ‘방법을 알고 있다 / 설명할 수 있다’를 묻습니다. 학습 버전 2로 저장하며 기존 세로형 응답과 분리됩니다.
- 기본·보충·심화는 본문 설명이며 별도 학습 분기 기능을 추가하지 않았습니다.

## 이미지 제작과 외부 연결

사용자가 이후 제공한 5장 인포그래픽을 참고해 뉴스레터 전용 삽화를 imagegen으로 새로 제작했습니다. 원본에서 직접 잘라낸 이미지가 아닙니다. 그림 속 제목과 설명은 제외하고, 문서·통화 / 읽기·쓰기 / 경청·표현·외국어 / 사전확인·학습 자료 / 재학습·다음 단계의 의미를 장별 사무실 장면으로 재구성했습니다. 베이지·파랑과 동일한 인물 스타일을 목표로 했으며 각 그림은 독립 PNG입니다. 웹 텍스트는 변경하지 않습니다.

이미지 제작 비율은 1026:1046(513:523의 2배)을 요청했습니다. 실제 출력 픽셀은 생성 도구가 정하며 원본 해상도를 유지한 채 513×523px 영역에 비율 유지 cover로 표시합니다. 모서리는 CSS 16px입니다. 인물과 주요 소품은 안전 영역 안에 배치하도록 요청했습니다. 파일 및 제작 기준은 `public/web/assets/picture/newsletter-final-illustrations.md`를 참조하세요.

퀴즈는 앞선 요청대로 다른 폴더에서 관리합니다. 완료 버튼의 `cardnews:quiz-request` 이벤트와 콘텐츠 ID 전달을 검증했으며 실제 퀴즈 주소나 외부 수신 처리는 미설정입니다. 내부 퀴즈를 복구하지 않았습니다.

## 확인

격리된 PC Chrome 1440px에서 5장 전체 원고 필드의 DOM 반영, 배치 지시 비노출, 1200×675 실제 치수, 박스·강조 영역·하단 팁의 겹침 없음, 카테고리, 이전·다음·페이지 점, 전·후 자기진단, 마지막 카드 복귀, 응답 3/5 저장, 완료 화면과 퀴즈 연결 이벤트를 확인했습니다. 외부 퀴즈의 실제 실행은 남은 작업입니다.
