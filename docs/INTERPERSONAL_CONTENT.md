# 함께 일하는 대인관계능력

- 콘텐츠 ID `workplace-interpersonal`, 카테고리 `etiquette`(직장 관계 & 예절). ‘전체’에도 표시됩니다.
- 확정된 1200×675 가로형 뉴스레터 템플릿을 재사용합니다. 섹션·서체·색상·버튼·75% 딤과 학습 완료 화면은 기존 콘텐츠와 동일합니다.
- 5장: 협력 관계 / 감정은행계좌와 신뢰 / 상호 도움과 한계 / 관심·감사·약속·일관성 / 자기존중과 경계.
- 사용자 제공 인포그래픽을 읽을 수 있는 교육 문장으로 재구성했습니다. 출처 불명의 ‘연구 결과’, 성공 순위와 인과 주장은 옮기지 않았습니다. 감정은행계좌는 비유로 설명하고, 배려를 일방적 희생이나 관계의 거래로 표현하지 않습니다. 사례는 ‘학습용 예시’로 표시합니다.
- 원고: `public/web/js/data/interpersonal-content.js`. 삽화: `public/web/assets/picture/interpersonal-scenes.png`.
- 삽화는 imagegen으로 새로 제작한 3열×2행 시트 중 5개 셀입니다. 원본 추출물이 아닙니다. 여섯 번째 셀은 비어 있습니다. 문구·수치·로고 없이 협력, 돼지저금통 신뢰 비유, 서로 돕기, 일상 습관, 존중하는 경계 표현을 묘사했습니다.
- 렌더러가 콘텐츠별 데이터와 이미지를 받도록 공통화했습니다. 기존 의사소통 콘텐츠의 원고·응답·이미지는 유지됩니다.
- 저장: `genz:cardnews-learning:v1:workplace-interpersonal`. 전·후 질문은 같은 학습 목표를 사용하며 자기평가 1~5로 저장합니다.
- 완료의 ‘퀴즈 풀러 가기’는 기존 `cardnews:quiz-request` 이벤트에 새 콘텐츠 ID를 전달합니다. 내부 퀴즈는 추가하지 않았으며 별도 폴더의 실제 연결은 미설정입니다.

## 검증

PC Chrome 1440px에서 카테고리 분리, 5장 전체 원고 표시, 1200×675 치수, 본문·강조·핵심 정리 겹침 없음, 이미지 디코딩, 이전·다음·페이지 점, 전·후 자기진단, 마지막 카드 복귀, 3/5 응답 저장, 완료 화면 중앙 정렬, 퀴즈 요청 이벤트를 확인했습니다. 기존 의사소통 카드의 같은 흐름도 재검증했습니다.
