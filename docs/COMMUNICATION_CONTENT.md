# 직장에서 통하는 의사소통

## 최신 변경: 퀴즈 분리

퀴즈 문항 데이터, 실행 컴포넌트, 채점·해설·결과·복습 화면과 전용 CSS를 현재 콘텐츠에서 제거했습니다. 아래의 퀴즈 관련 설명과 검증 결과는 분리 전 기록입니다.

현재 흐름은 학습 전 자기진단 → 카드뉴스 → 학습 후 자기진단 → 완료 화면까지입니다. ‘퀴즈 풀러 가기’는 `cardnews:quiz-request` 이벤트만 발생시키며 화면을 전환하지 않습니다. 이벤트의 `detail.contentId`로 대상 콘텐츠를 전달합니다. 별도 퀴즈 폴더의 실제 경로나 연결은 아직 설정하지 않았습니다. 기존 자기진단 저장은 유지하며 새 퀴즈 점수는 기록하지 않습니다.

## 등록과 학습 흐름

- ID: `workplace-communication`, type: `communicationGuide`.
- 주 카테고리 `communication`, 보조 카테고리 `collaboration`. 기존 7개 목록을 재사용합니다.
- `data/communication-content.js`가 기존 `CARDNEWS_CONTENTS` 목록에 신규 콘텐츠를 추가합니다. 기존 두 콘텐츠는 유지합니다.
- 학습 전 자기진단 → 내용 카드 5장 → 마지막 카드의 퀴즈 시작 → 학습 후 자기진단 → 학습 완료 → 퀴즈 풀러 가기.
- 신규 콘텐츠의 마지막 장은 실제 학습 내용입니다. 기존 기사 콘텐츠의 마지막 빈 장에서 자기진단을 여는 동작과 구분합니다.
- 카드 본문·문항·선택지·해설은 데이터 파일에서 수정합니다. 텍스트를 이미지로 굽지 않았습니다.
- 현재 시각 스타일은 기존 크림색 바탕·블루 강조·베이지 팁 박스로 통일했습니다. 첨부 삽화를 참고해 글자 없이 재구성한 `communication-illustrations.png`와 기존 공통 종 아이콘을 사용합니다. 원본 이미지를 그대로 잘랐다고 주장하지 않습니다.

## 교정 및 출처

- 원자료: 사용자가 제공한 의사소통능력 인포그래픽 5장.
- 불명확한 글자, 중복 번호, 인물 이름·인용문을 그대로 전사하거나 원문을 복원했다고 주장하지 않습니다.
- 하위능력은 문서이해능력, 문서작성능력, 경청능력, 의사표현능력, 기초외국어능력으로 정리했습니다.
- 확인한 자료: [한국산업인력공단 NCS 의사소통능력 자료](https://ncs.go.kr/th03/TH0302List.do?dirSeq=121)의 구조보기·의사소통능력 온라인 학습 목록. 이 링크는 하위능력 분류를 확인한 자료이며 첨부 이미지의 원출처로 단정하지 않습니다.
- 이미지 제작자, 제작 시기, 이미지가 인용한 가이드북의 정확한 판본·페이지, 인물 인용의 원출처는 추가 확인이 필요합니다.
- 업무 상황과 퀴즈는 학습용 창작이며 실제 사건·연구 수치로 제시하지 않습니다. 가이드북 본문을 그대로 재배포하지 않습니다.

## 카드·평가 연결

| 카드 | 핵심 내용 | 퀴즈 |
| --- | --- | --- |
| 1 | 목적·결과물·기한 확인 | 모호한 지시를 확인하는 대응 |
| 2 | 다섯 하위능력과 업무 예시 | 메일의 결과물·기한·제출 경로·첨부 조건 파악 |
| 3 | 확인된 사실과 해석 구분 | 수정 대상과 필요한 근거 기준 질문 |
| 4 | 구체적 전달·경청·요약·채널 조합 | 긴급한 대화와 합의 기록 병행 |
| 5 | 핵심 원칙 요약과 자기진단 | 역할·조건·기한의 공동 이해 확인 |

정답 인덱스는 1·3·0·2·0(0부터 시작)이며, 각 문항에는 정답 하나와 선택지별 해설이 있습니다. 정답 공개는 제출 후 결과 화면에서 합니다.

## 응답 저장

- 자기진단: 기존 `genz:cardnews-learning:v1:<ID>`에 `preResponse`, `postResponse` 1~5 저장.
- 퀴즈: 별도 `genz:cardnews-quiz:v1:<ID>`에 문항 ID·선택 인덱스·정오·정답 수·문항 수·100점 환산 점수·버전·완료 시각 저장.
- 두 기록은 서로 덮어쓰지 않습니다. 브라우저 로컬 저장이며 서버 전송은 없습니다.
- 저장이 차단되면 페이지 메모리로 보관하고 결과에 안내합니다.
- 오답 해설은 자동으로 펼쳐지고, 모든 선택지의 해설과 관련 카드로 가는 버튼을 제공합니다. 다시 학습한 뒤 결과로 돌아와도 점수와 답을 유지합니다.

## PC 검증

`node scripts/verify-communication-course.cjs` (격리된 Chrome 프로필 사용).

- 전체·질문/소통·협업 필터 표시 및 다른 분류에서 제외, 기존 콘텐츠 유지.
- 다섯 카드 4:5 비율, 125% 확대(525×656.25px), 잘림·페이지 점 겹침 없음.
- 내용이 DOM 텍스트인지, 다섯 하위능력과 출처·마지막 퀴즈 시작 버튼 표시 확인.
- 자기진단 전·후, 이전 카드 복귀, 선택 전 제출 차단, 문항 이전·다음 및 선택 유지 확인.
- 혼합 응답 4/5(80점), 재도전 5/5(100점), 해설 20개, 오답 카드 복습·결과 복귀 확인.
- 자기진단과 퀴즈 별도 저장, 기존 기사 카드뉴스의 학습 후 팝업 흐름 확인.
- 모바일은 이번 검증 범위가 아닙니다.
