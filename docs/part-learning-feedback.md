# 파트 안의 답안에 근거한 학습 항목 피드백

현재 결과 화면에서는 ‘같은 파트의 재응시 변화 보기’ 영역을 제거했습니다. 두 피드백 카드는 이번 응시의 답안으로 계산하며, 현재 선택 답안이 없는 과거 화면을 복구할 때만 저장 답안을 조회합니다. 기존 학습 기록·관리자 화면의 비교와 Supabase 자동 저장은 유지합니다. 화면 영역 제거를 위해 적용된 SQL이나 저장 기록을 삭제할 필요는 없습니다.

2026-10-20에 실제 Supabase `lt_catalog()`의 공개 카탈로그를 읽어 확인했습니다. 7파트 각각 7문항, 총 49문항이며 현재 버전은 모두 revision 1입니다. 원본 질문·선택지·정답·해설·보기별 피드백을 확인한 뒤 문항별 항목을 연결했습니다. 파트 제목이나 점수만으로 항목을 분류하지 않았습니다.

## 적용 방식

- `src/app/quiz/learning-item-review.json`: 검토한 각 문제의 UUID·revision·퀴즈 버전 UUID, 원문/선택지/정답의 일치 확인 값, 세부 항목과 복습 안내입니다.
- `src/app/quiz/learning-feedback.ts`: 현재 파트의 답안에서 항목별 정답·오답 근거를 계산합니다. 다른 파트의 점수나 답안을 사용하지 않습니다.
- `src/app/quiz/PartLearningFeedback.tsx`: 완료 화면에서 ‘잘 이해한 내용’과 ‘한 번 더 확인할 내용’을 두 카드로 보여 줍니다. 항목명과 혼합 정오답 안내만 표시하고, 각 항목의 ‘복습 내용 · 관련 문제 보기’ 펼침 영역은 제거했습니다. 첫 응시의 피드백은 현재 답안으로 즉시 계산하므로 이전 기록이나 외부 AI 호출이 필요하지 않습니다.
- 제출한 보기 ID를 기존 진행 상태와 함께 보관하여 새로고침에도 유지합니다. 기존 점수 계산·Supabase 답안 이벤트·서버 채점·응시 저장 방식은 유지합니다. 새 SQL은 추가하지 않았습니다.
- 같은 항목의 관련 문제에서 정답과 오답이 섞이면 보완할 부분에 **일부 상황은 이해했지만 추가 확인이 필요해요**라고 표시합니다. 안정적인 강점·약점, 실제 업무 능력으로 단정하지 않습니다.
- 복수 선택 문항이 틀렸다고 모든 항목을 보완 대상으로 분류하지 않습니다. 항목별로 실제 관련된 잘못 선택한 보기·선택하지 않은 정답을 확인합니다. 일부 보기만 맞은 오답 문항을 정답 문항으로 취급하지도 않습니다.
- 예를 들어 조직 이해·적응 Q5는 우선순위, 험담, 회의 준비, 프린터 사용 후 정리, 이전 경험 검토를 포함하므로 서로 다른 항목으로 연결했습니다. 회의 준비와 프린터 점검은 같은 선택지에 묶여 있어 독립적으로 평가한 결과가 아니라는 점도 표시합니다.
- 문제 UUID·revision·소속 퀴즈 버전·문구·선택지·정답 중 검토한 내용과 다른 것이 있으면 기존 항목을 임의로 재사용하지 않습니다. 그 문제의 답안·정답·해설과 항목 연결 검토 필요 안내만 표시합니다.
- 이전 화면에서 선택 답안을 보관하지 않았던 경우 점수나 오답 ID에서 답을 추정하지 않습니다. 저장된 본인 답안을 불러와 표시하며, 조회되지 않는 동안에는 근거가 있는 문항만 안내합니다.

## 재응시 비교

기존 학습 기록 마이그레이션 `202610200001_learning_history.sql`의 RLS와 `lt_learning_records` invoker 뷰를 재사용합니다. `/api/learning/part-feedback`은 서버에서 Auth 토큰을 검증한 뒤 본인의 현재 완료 응시와 **같은 퀴즈 버전 UUID·문제 버전 ID 순서·응시 유형**의 직전 완료 응시만 읽습니다. 운영자가 이 사용자용 API를 사용해도 본인의 기록만 읽습니다.

이전 응시와 이번 응시의 같은 문항·항목을 대조해 오답→정답으로 바뀐 근거와 정답→오답으로 다시 확인할 근거를 구분합니다. 오답인 복수 선택 문항에서 해당 항목을 별도로 판단할 근거가 없었다면, 이후 정답이 되어도 그 항목을 개선됐다고 추정하지 않습니다. 전체 응시와 오답 복습, 다른 복습 구성, 미완료 기록은 서로 비교하지 않습니다. 기록이 없으면 이번 답안만 안내하고, 저장 대기·조회 실패는 재확인 안내를 표시합니다. 단순 답안 변화이며 학습 효과나 실제 능력 향상의 입증으로 표현하지 않습니다.

## 검증

실제 49문항 카탈로그를 회귀 테스트 자료로 보관했습니다. 모든 문항의 연결과 보기 ID, 첫 응시, 혼합 정오답, 복수 선택의 놓친/잘못 고른 보기, 변경된 문제의 연결 차단, 답안 미확인 시 추정 금지, 같은 구성의 재응시 변화, 사용자 간 접근 차단과 서버의 비교 대상 필터를 테스트합니다. 실제 Supabase 응시 데이터는 테스트 목적으로 추가·수정하지 않습니다.
