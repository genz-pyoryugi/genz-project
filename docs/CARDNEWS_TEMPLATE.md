# 카드뉴스 템플릿 적용 기준

뉴스레터형 가로 내지는 별도 기준인 [NEWSLETTER_TEMPLATE.md](NEWSLETTER_TEMPLATE.md)를 따릅니다. 아래 세로형 수치와 혼용하지 않습니다.

현재 코드와 사용자의 수정 요청을 기준으로 정리한 유지 규칙입니다. 개별 변경의 작성자는 Git 기록만으로 구분할 수 없으므로 특정 변경을 사용자 작성으로 단정하지 않습니다.

- 기준 원본은 `first-day-cardnews.js`의 ‘신입사원 첫 출근 적응 가이드’. 새 카드도 이 템플릿의 좌표·비율을 따른다. 분위기가 비슷한 수준으로 임의 배치하지 않는다.
- 1080×1350, 4:5, Pretendard. 바탕 `#fdf9f2`, 강조 `#086bce`, 제목 `#202b33`, 팁 배경 `#f1e8d8`, 팁 글자 `#175487`. 기존 125% 콘텐츠 확대와 상단 카테고리 크기를 유지한다.
- 상단은 짧은 작은 진한색 제목과 큰 파란 핵심 문구. 원본 캔버스의 x=64, 기준선 y=90/157, 글자 크기 39/62를 기준으로 환산한다. 긴 문구는 디자인을 바꾸기보다 의미를 유지하며 짧게 다듬는다. 문구 수정은 사용자가 요청한 범위에서만 한다.
- 1~4장의 팁 박스는 내용 길이와 관계없이 고정 위치. 원본 좌표 x=64, y=1085, 너비=952, 높이=158. 종 아이콘은 x=102.4, y=1106.4, 너비=115.2. 공통 종과 기존 모션을 재사용한다.
- 팁에 본문이 침범하지 않도록 본문 하단 공간을 확보한다. 내용이 많을 때는 삽화 영역과 간격을 조절하고, 공통 제목·팁 위치를 움직이지 않는다.
- 의사소통 카드 5장은 요약용 베이지 박스 4개, 삽화와 종 팁 없음. ‘더 알아보기’는 기존 ‘원문보기’와 동일한 위치·크기로 NCS 링크를 연다.
- 의사소통 덱은 내용 5장 + 학습 후 상태 확인용 빈 칸 1개, 총 6칸. 마지막 칸에 딤 처리된 팝업을 표시하고 왼쪽 화살표로 5장에 복귀한다. 자기진단과 퀴즈 점수는 구분한다.
- 카테고리: 치명적 실수=`communication`, 첫 출근 적응 가이드=`etiquette`, 의사소통=`collaboration`. 각 콘텐츠는 지정 카테고리 하나와 ‘전체’에만 표시한다.
- 확인할 때 제목의 크기·색·여백뿐 아니라 팁·아이콘의 실제 좌표, 페이지 점과의 간격, 텍스트 잘림·겹침을 PC 브라우저에서 비교한다.

주요 구현: `public/web/css/communication-learning.css`, `public/web/js/components/communication-cardnews.js`, `public/web/js/components/cardnews-learning.js`. 콘텐츠 문구는 `public/web/js/data/communication-content.js`에서 편집한다.
