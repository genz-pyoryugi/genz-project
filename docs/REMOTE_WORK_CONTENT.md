# 재택근무, 일과 소통의 기준 세우기

- ID `remote-work-agreements`, 카테고리 `work-rules`(근무 & 재택 수칙), 기존 가로형 템플릿 1200×675의 5장.
- 원문은 2020년 재택근무 확산 초기의 업무 분담, 응답·성과 입증 부담과 적응 사례를 다룬 기사입니다. 당시 보도를 현재 모든 회사의 감시·근무 규정으로 일반화하지 않았습니다.
- 카드 구성: 목표·역할·기한 / 작업 환경과 준비 / 연락·응답 합의 / 결과·막힘·다음 행동 공유 / 근무 경계와 다음 인계.
- 기사 요약을 장문 전재하지 않고 핵심 문제를 출발점으로 자체 학습 활동과 가상 대화를 작성했습니다. 추가 사례는 ‘학습용 예시’, 활동은 ‘실천 방법’으로 구분합니다. 근무시간·도구 기록 범위는 해당 조직의 안내와 합의를 확인하도록 설명하며 법적 판단을 제시하지 않습니다.
- 데이터 `public/web/js/data/remote-work-content.js`, 그림 `public/web/assets/picture/remote-work-scenes.png`.
- 삽화는 imagegen으로 새로 제작한 3열×2행 중 5개 장면입니다. 글자·로고 없이 원격 목표 합의, 집중 준비, 연락 조율, 진행 공유, 업무 마무리를 표현합니다. 마지막 셀은 비어 있습니다.
- 마지막 카드의 원문보기: https://www.donga.com/news/Society/article/all/20200321/100261696/9 . 상단 라벨과 같은 높이이며 새 탭으로 열립니다.
- 전·후 자기진단 저장 키 `genz:cardnews-learning:v1:remote-work-agreements`. 완료 후 퀴즈 요청 이벤트에 같은 ID를 전달합니다. 별도 폴더의 퀴즈 주소는 미설정입니다.

PC Chrome에서 전체 6개 콘텐츠 유지, 전체·근무/재택 카테고리 노출, 5장 원고와 이미지 로딩, 1200×675 치수, 잘림·겹침 없음, 이전·다음·페이지 점, 전·후 모달과 마지막 카드 복귀, 응답 저장, 완료 화면·퀴즈 이벤트, 원문 주소·새 탭·버튼 높이를 확인했습니다.
