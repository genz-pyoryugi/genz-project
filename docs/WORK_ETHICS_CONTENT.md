# 원칙을 지키는 직업윤리

- ID `workplace-ethics`, 기존 가로형 템플릿 1200×675, 내용 5장과 전·후 자기진단.
- 별도 카테고리 지정이 없어 업무 기준·공정한 절차를 다루는 `procedures`(업무 절차 & 기준)에 등록했습니다. ‘전체’에도 표시됩니다.
- 원고: `public/web/js/data/work-ethics-content.js`. 학습 내용: 윤리적 갈등 / 근로윤리와 공동체윤리 / 공과 사 구분 / 실천 체크리스트 / 신뢰받는 일터.
- 첨부 자료의 중복된 3장 번호를 정리했습니다. 교통 단속 예시는 업무 승인 사례로 재구성해 ‘학습용 예시’로 표시했습니다. 법적 처분이나 특정 규정 내용을 새로 단정하지 않았습니다.
- 정확한 NCS 판본·페이지와 하단의 불명확한 인용은 확인되지 않아 공식 인용이나 출처 URL을 만들지 않았습니다. 일반적인 교육 문장으로 재작성했습니다.
- 삽화 `public/web/assets/picture/work-ethics-scenes.png`는 첨부 자료의 의미를 참고해 imagegen으로 새로 만든 3열×2행 시트입니다. 첫 5개 셀은 윤리적 고민, 두 관점의 저울, 공정한 절차 안내, 체크리스트, 책임 있는 협력입니다. 여섯 번째 셀은 비어 있습니다. 제목·본문은 이미지에 넣지 않고 웹 텍스트로 표시합니다.
- 저장 키 `genz:cardnews-learning:v1:workplace-ethics`. 전·후 같은 학습 목표에 대해 1~5 자기평가를 저장합니다.
- 퀴즈는 기존대로 다른 폴더에서 관리하며 완료 버튼의 `cardnews:quiz-request` 이벤트에 이 콘텐츠 ID를 전달합니다. 실제 퀴즈 주소는 미설정입니다.

PC Chrome에서 카테고리 노출, 전체 3개 콘텐츠 유지, 5장 원고·이미지 표시, 실제 크기, 텍스트 잘림·겹침, 탐색, 전·후 자기진단·마지막 카드 복귀·응답 저장, 완료 화면과 퀴즈 이벤트를 확인했습니다.
