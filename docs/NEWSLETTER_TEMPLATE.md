# 뉴스레터형 카드뉴스 내지 기준

실제 1~5장 원고 적용과 최신 본문 규격, 미수신 이미지 및 외부 퀴즈 연결 상태는 [NEWSLETTER_CONTENT.md](NEWSLETTER_CONTENT.md)를 우선 참조합니다.

사용자가 지정한 1번 내지 화면과 현재 구현을 기준으로 정리했습니다. 세로형 카드 템플릿과 별개로 적용하며, 이번 분석으로 화면 코드는 변경하지 않습니다.

## 전체 구조

- PC 기준 1200 × 675px, 16:9. 안쪽 여백 20px, 카드 모서리 20px.
- 위쪽은 이미지와 본문을 나란히 두고, 아래쪽은 전체 폭의 핵심 정리와 탐색 영역으로 구분합니다.
- 상단 두 열의 간격은 20px, 남은 폭을 45:55로 분배합니다. 기준 폭에서 이미지 영역 513px, 본문 영역 627px입니다.
- 콘텐츠가 짧아도 남는 공간을 유지합니다. 글자나 박스를 억지로 늘려 채우거나, 핵심 정리·탐색 위치를 위로 당기지 않습니다.
- 본문 길이에 따라 상단 영역의 높이가 바뀌지 않도록 아래 영역은 축소되지 않는 구조를 유지합니다. 작은 화면에서는 별도 반응형 세로 배치를 사용합니다.

## 표현과 예외

- 삽화는 실제 업무 행동을 우선합니다. ‘문서 이해=돋보기’처럼 개념을 일차원적인 상징물로 치환하지 않습니다. 문서 검토는 문서를 읽고 항목을 짚거나 동료와 확인하는 모습으로 표현합니다. 도구·자료는 사용하는 사람 기준으로 자연스럽게 배치합니다.

- 바탕 `#fdf9f2`, 영역 배경 `#f1e8d8`, 기본 글자 `#202b33`, 메인 강조 `#086bce`, 설명 제목·핵심 정리 `#175487`, 일반 항목 배경 `#fffcf7`, 항목 테두리 `#e9e0d2`. 글꼴 Pretendard.
- 사례 항목은 베이지 면으로 강조하고 ‘학습용 예시’를 표시합니다. 일반 항목은 밝은 바탕과 얇은 테두리로 구별합니다.
- 아이콘은 장식과 의미 보조 용도입니다. 제목과 본문을 이미지에 포함하지 않고, 각 요소를 독립된 웹 레이어로 유지합니다.
- 사례 유무와 항목 수는 학습 내용에 따라 달라질 수 있습니다. 예시 화면의 4개 항목을 모든 장에 강제하지 않습니다. 다섯 하위능력처럼 필요한 항목은 유지하고, 잘림·겹침을 확인합니다.
- ‘뉴스레터 형식 · 테스트 콘텐츠’, 삽화 설명, `null`, ‘1 / 5’ 숫자는 표시하지 않습니다. 페이지 점만 사용합니다.
- 마지막 장에서도 오른쪽 버튼은 ‘다음’이며, 클릭하면 기존 학습 후 모달을 표시합니다. ‘더 알아보기’는 별도의 우상단 보조 링크입니다.
- 학습 전·후 모달과 완료 화면은 내지와 구분되는 상태 화면입니다. 내지의 두 열 규칙을 적용하지 않습니다. 카드 전체 크기와 톤은 유지합니다.

## 이후 제작 시 확인

### 1번 카드 기준으로 통일한 최신 내지 규격

이 항목은 위 표의 초기 글자 크기보다 우선합니다. 1번에만 적용하던 제목·설명 스타일을 1~5번 공통 규칙으로 전환했습니다.

- 주제 라벨: 18px/800, 내부 여백 6px 16px. 메인카피: 36px/800, 줄 높이 1.25, 아래 여백 16px.
- 사례: 64px 문서 아이콘, 베이지 면, 18px 16px 내부 여백. 작은 사례 라벨과 본문을 구분하고, 직접 요청 문장으로 시작할 때만 해당 문장을 굵게 분리합니다.
- 일반 항목: 최소 높이 56px, 내부 여백 8px 14px. 40px 아이콘 → 제목 → 세로 구분선 → 설명의 가로 구조.
- 1번의 짧은 제목은 66px/18px, 나머지 장의 긴 개념 제목은 118px/16px. 설명은 1번 14px, 나머지 13px로 내용 밀도에 맞추며 원문을 누락하지 않습니다.
- 모든 장의 항목 아래에 베이지 인용 박스를 배치합니다. 1번은 확인 질문, 나머지는 기존 takeaway를 재사용하며 새 사례나 인용 출처를 만들지 않습니다.
- 핵심 정리: 제목 17px/800, 문장 16px/700. 탐색과 핵심 정리의 공통 위치 유지.
- 1번의 개별 삽화는 왼쪽 섹션을 cover로 채웁니다. 나머지 장의 기존 시트 삽화는 비율을 유지해 같은 크기의 이미지 섹션 안에 배치하며, 새 삽화를 생성한 것으로 설명하지 않습니다.

1. 주제 라벨·메인카피·설명·핵심 정리의 역할을 구분해 콘텐츠를 작성합니다.
2. 글자 수가 많다고 카드 크기·열 비율·핵심 정리 위치를 장마다 바꾸지 않습니다. 사용자 승인 없이 내용을 누락하거나 의미를 바꾸지 않습니다.
3. 5장 전체에서 이미지 영역, 본문 시작선, 핵심 정리와 탐색 영역이 일관되는지 비교합니다.
4. 실제 PC 화면에서 본문 잘림, 항목 겹침, 핵심 정리 침범, 탐색 동작과 모달 연결을 확인합니다.
