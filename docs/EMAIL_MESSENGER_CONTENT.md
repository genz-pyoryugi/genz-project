# 메일과 메신저, 업무에 맞게 함께 쓰기

- ID `email-messenger-communication`, 카테고리 `communication`(질문 & 소통), 가로형 카드뉴스 5장.
- 구성: 소통 방식의 엇갈림 / 빠른 질문과 응답 / 기록과 관계자 공유 / 메일과 메신저 병행 / 팀의 채널 선택 기준.
- 사용자가 제공한 인포그래픽과 지정 기사 본문을 확인하고 교육용 문장으로 재구성했습니다. 온라인 커뮤니티의 사연을 특정 세대 전체의 검증된 특성으로 제시하지 않습니다. 메일만 공식 기록이라는 단정 대신 조직에서 지정한 기록 채널을 따르도록 설명합니다.
- 원고의 추가 대화는 학습용 예시이며 실제 발언의 직접 인용으로 표시하지 않습니다. 법적 증거 효력이나 특정 도구의 기능을 보장하지 않습니다.
- 5번째 카드의 ‘원문보기’는 https://www.donga.com/news/Society/article/all/20260622/134157708/1 를 새 탭으로 엽니다. 버튼 위치·높이는 라벨과 동일한 행입니다.
- 데이터: `public/web/js/data/email-messenger-content.js`. 삽화: `public/web/assets/picture/email-messenger-scenes.png`.
- 삽화는 imagegen으로 새로 제작한 3열×2행 중 5개 장면입니다. 동일한 동료들의 채널 차이, 빠른 대화, 기록, 알림 병행, 공동 기준을 나타내며 실제 서비스 로고와 글자는 넣지 않았습니다. 마지막 셀은 비어 있습니다.
- 전·후 자기진단은 동일 학습 목표에 대응하며 `genz:cardnews-learning:v1:email-messenger-communication`에 저장합니다. 퀴즈는 별도 폴더 연결용 이벤트만 유지합니다.

PC Chrome에서 전체 5개 콘텐츠 유지, 전체·질문/소통 카테고리 노출, 5장 원고·이미지·1200×675 치수, 잘림·겹침 없음, 카드 이동, 전·후 모달·마지막 카드 복귀·응답 저장, 완료 화면·퀴즈 이벤트, 원문 주소·새 탭·라벨과 버튼 정렬을 확인했습니다.
